Why today’s outcome was not ideal

为什么今天的结果不理想

The system became better at noticing possible omissions, but not yet good enough at reconstructing the missing scientific evidence.

系统更善于发现“可能漏了什么”，但还不能稳定地重建缺失的科学证据。

01

Compression was too aggressive

压缩过度

A large local packet was reduced to a much smaller API packet. Important paragraphs, table cells, or experiment boundaries could fall outside the selected evidence.

庞大的本地证据包被压缩成很小的 API 输入，重要段落、表格单元格或实验边界可能没有被选中。

02

Schema validity was mistaken for completeness

把格式正确误当成内容完整

The schema checked whether returned records had valid fields. It could not prove that every experiment in the paper had produced a record.

Schema 能检查返回记录的字段是否合法，但无法证明论文里的每个实验都已经生成了记录。

03

Recovery prompts lacked structured visual input

恢复提示缺少结构化视觉输入

Repeated calls were asked to recover evidence before tables and figures had been reliably parsed into rows, panels, labels, values, and relationships.

在表格与图片尚未稳定解析为行、列、面板、标签、数值和关系之前，就反复要求模型恢复证据，成功率自然有限。

What kept going wrong

反复出现的错误

Each patch addressed a visible symptom, but the underlying document-understanding layer was still incomplete.

每次修改都处理了一个表面症状，但底层的文档理解能力仍然不完整。

The proposed fix

建议的解决方案

Improve what the extraction model receives: structured document objects first, then a small evidence-focused prompt.

先改善模型接收到的信息：先生成结构化文档对象，再发送小而精准的证据提示。

Docling

A local document parser that can preserve reading order and turn PDF layout into explicit objects.

本地文档解析工具，可保留阅读顺序，并把 PDF 版面转换成明确的文档对象。

  • Sections and reading order
  • Table rows, columns and cells
  • Captions and figure boundaries
  • Coordinates and provenance
  • 章节与阅读顺序
  • 表格行、列和单元格
  • 图注与图片边界
  • 坐标与来源信息

Local VLM · Gemma via Ollama

本地 VLM · Ollama 运行 Gemma

A local vision-language model that inspects only the relevant figure or table object.

本地视觉语言模型，只检查真正相关的图片或表格区域。

  • Printed labels and numeric values
  • Panel and legend relationships
  • Cell-marker colocalization
  • Uncertainty and abstention
  • 印刷标签与数值
  • 面板与图例关系
  • 细胞标记共定位
  • 不确定性与主动拒答
The goal is not to send more PDF text to an LLM. The goal is to convert each relevant visual object into a compact, traceable observation—panel, row, column, label, value, unit, relationship and uncertainty—then normalize only that evidence. 目标不是把更多 PDF 文本发送给 LLM。目标是把每个相关视觉对象转换成紧凑且可追溯的观察记录——面板、行、列、标签、数值、单位、关系和不确定性——然后只对这些证据进行标准化。

Future steps

下一步

Progress should be measured by reproducible evidence recovery, not by whether another model call completed.

后续进展应以可复现的证据恢复率衡量，而不是以“是否又完成了一次模型调用”衡量。

Resume and verify local Gemma

继续下载并验证本地 Gemma

Test real gold-set figures and tables. Compare its structured observations with known values and record failures honestly.

使用真实金标准图片和表格测试，并把结构化观察与已知数值逐项比较，真实记录失败情况。

Add Docling object extraction

加入 Docling 对象提取

Create stable table, caption and figure objects with coordinates, checksums and source provenance.

生成稳定的表格、图注和图片对象，保存坐标、校验值和来源信息。

Define visual-observation contracts

定义视觉观察数据结构

Require exact object IDs, locations, printed values, units and uncertainty. Reject unsupported inference and visual estimation.

强制保存对象 ID、位置、印刷数值、单位和不确定性，拒绝无证据推断与视觉估算。

Re-run the frozen 15-outcome gate

重新运行固定的 15 条结果测试

Measure final merged recovery, false additions, evidence accuracy, runtime and token cost. Do not pass the gate below the agreed target.

衡量最终合并恢复率、错误新增、证据准确性、运行时间和 token 成本。未达到目标不得通过质量门槛。

Expand discovery and full-text access

扩大论文发现与全文获取

Add OpenAlex, semantic retrieval and citation chaining; use open-access resolvers first and authorized university-library access when needed.

加入 OpenAlex、语义检索和引用链；优先使用开放获取来源，必要时使用经过授权的大学图书馆访问。
