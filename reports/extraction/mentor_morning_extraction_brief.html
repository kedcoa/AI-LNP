Attempt 1 · Morning foundation

尝试 1 · 上午基础

The Missing Map

“缺失的地图”

Cohesive extraction strategy统一提取策略
Design correction设计纠正

Previous problem

之前的问题

Repair tasks carried opaque candidate and experiment IDs but not enough compact scientific meaning. A provisional association could also set permitted_new_experiments to zero.

修复任务带有不透明的候选 ID 和实验 ID，却缺少足够的紧凑科学语义。临时关联还可能把 permitted_new_experiments 设为 0。

Pipeline solution

管线方案

Carry exact candidate facts, evidence and compact experiment summaries; explicitly link candidate → outcome → experiment; permit one bounded new experiment; route text and visual repairs separately.

携带精确候选事实、证据和紧凑实验摘要；明确关联候选→结果→实验；允许一个受限新实验；把文本修复和视觉修复分开。

What this established

这一阶段确定了什么

The pipeline needed one coordinated contract over existing ingestion, Docling, local candidate, vision, validation and merge stages—not another independent extractor.

需要的是一个协调现有摄取、Docling、本地候选、视觉、验证与合并阶段的契约，而不是再造一个独立提取器。

尝试 2 · NP-001 主调用与强制试验

One Good Record, Thirty-Five Silences

“一条好记录，三十五次沉默”

Primary extraction → The Forced Census主提取 → “强制人口普查”
1/36 → 36/36, still failed1/36 → 36/36，仍失败

Why the first call failed

第一次调用为何失败

The prompt showed 36 candidate outcomes, but the answer format did not force an individual decision for each. The model produced one easy, complete HepG2 record and silently stopped.

提示中有 36 个候选结果，但答案格式没有强制逐项决定。模型生成了一条容易且完整的 HepG2 记录后便停止。

Forced-accounting solution

强制核算方案

Make every candidate ID a required response item so all 36 must receive a disposition and a candidate–outcome–experiment link.

把每个候选 ID 设为必答项，使全部 36 个候选都必须获得处置以及候选—结果—实验关联。

Why that also failed

为何仍然失败

Completeness of labels is not scientific completeness. The model accounted for 36/36 by dismissing most candidates as “not outcome” or “insufficient evidence,” even though it could form one valid outcome.

标签完整不等于科学完整。模型虽然核算了 36/36，却把大部分候选判为“不是结果”或“证据不足”，尽管它能够形成一条有效结果。

What the original LLM call successfully extracted

原始 LLM 调用成功提取的内容

  • LNP(DSPC)/DX25 with ALC-0315, DSPC, cholesterol, DX and ALC-0159.
  • DX replaced 25% of cholesterol; N/P ratio 6.
  • EGFP-encoding mRNA delivered to human HepG2 cells in vitro.
  • 500 ng total mRNA per well, measured at 24 h.
  • Approximately 95% of HepG2 cells were EGFP-positive.
  • LNP(DSPC)/DX25，组分包括 ALC-0315、DSPC、胆固醇、DX 和 ALC-0159。
  • DX 替代 25% 胆固醇；N/P 比为 6。
  • 在体外向人 HepG2 细胞递送编码 EGFP 的 mRNA。
  • 每孔总 mRNA 500 ng，24 小时测量。
  • 约 95% 的 HepG2 细胞呈 EGFP 阳性。
Important nuance:重要区别： the one record was scientifically useful, but it did not prove paper-level recall. The 95% result was also reported collectively across LNP, LNP/DX25 and LNP/DX50 rather than as a clean DX25-only value.这条记录具有科学价值，但不能证明论文级召回完整；而且 95% 的结果是对 LNP、LNP/DX25 和 LNP/DX50 的整体描述，并非清晰的 DX25 单独数值。

Attempt 3 · NP-001 global core-slot trial

尝试 3 · NP-001 全局核心槽位试验

The Duplicate Escape Hatch

“重复项逃生口”

Six core biological contexts in one call一次调用中的六个核心生物学情境
Schema complete, science invalid格式完整，科学无效

Previous problem

之前的问题

Thirty-six low-level candidates mixed real delivery outcomes with morphology, SAXS, stability, cytokines and repeated wording. Forcing all 36 encouraged easy dismissals rather than scientific synthesis.

36 个低层候选混合了真实递送结果、形态、SAXS、稳定性、细胞因子及重复表述。强迫处理全部候选反而鼓励简单驳回，而不是科学整合。

Pipeline solution

管线方案

Pre-qualify six biological slots: HepG2 transfection; DC2.4 transfection and immune response; hPBMC transfection and immune response; mouse biodistribution. Require each to be extracted or a legitimate duplicate.

预先确定六个生物学槽位：HepG2 转染；DC2.4 转染和免疫反应；hPBMC 转染和免疫反应；小鼠生物分布。要求每项被提取或成为合理重复项。

Actual result

实际结果

The model produced one HepG2 experiment and reused it as the “duplicate” answer for the other five contexts. The local scientific validator correctly rejected cross-cell and cross-outcome-family links.

模型生成一个 HepG2 实验，并把它当作其他五个情境的“重复”答案。本地科学验证器正确拒绝了跨细胞和跨结果类别的错误关联。

Lesson:结论： removing “insufficient evidence” closed one escape route, but “duplicate” became the new escape route. A global response still let the model satisfy the schema without doing six independent scientific analyses.删除“证据不足”堵住了一个逃生口，但“重复”成了新的逃生口。全局响应仍允许模型在不做六次独立科学分析的情况下满足格式。

Attempt 4 · NP-001 isolated contexts

尝试 4 · NP-001 隔离情境

One Scientist per Question

“每个问题一位科学家”

Six isolated, sequential calls六个隔离、顺序调用
Better records, wrong paper scope记录更好，论文范围不合适

Previous problem

之前的问题

One six-slot answer allowed record reuse. The model could avoid reasoning separately about HepG2, DC2.4, hPBMC and mouse contexts.

一个包含六槽位的答案允许重复利用记录，模型可以绕过对 HepG2、DC2.4、hPBMC 和小鼠情境的分别推理。

Pipeline solution

管线方案

Send one slot and only its relevant evidence per request. Require exactly one extracted record; forbid duplicate, unresolved and automatic retries.

每次请求只发送一个槽位及其相关证据。强制返回一条提取记录；禁止重复项、未解决项和自动重试。

Actual result

实际结果

HepG2 and DC2.4 transfection calls produced distinct, useful records. A later call became ambiguous, and the inherited liver-target requirement conflicted with non-liver DC2.4/hPBMC contexts.

HepG2 和 DC2.4 转染调用生成了不同且有用的记录。后续调用出现歧义，同时继承的肝细胞目标要求与非肝脏 DC2.4/hPBMC 情境冲突。

What this proved

这一阶段证明了什么

Narrow, context-specific calls materially improved scientific focus. But NP-001 was a poor final validation paper for a liver-only application because it intentionally contained non-liver cell lines. The next test therefore changed the paper, not merely the prompt.

狭窄、情境专一的调用显著提高了科学聚焦度。但 NP-001 包含非肝脏细胞系，不适合作为肝脏专用应用的最终验证论文。因此下一次测试改变的是论文，而不只是提示词。

Previous problem

之前的问题

NP-001 mixed liver and non-liver contexts. Even an accurate isolated call could be irrelevant to the current product scope.

NP-001 混合了肝脏和非肝脏情境。即使隔离调用准确，也可能与当前产品范围无关。

Pipeline solution

管线方案

Use a new paper whose experimental outcomes concern liver-resident cells, then ask one bounded liver-cell question per call while retaining formulation, payload, dose, route, model, assay and comparative evidence.

使用一篇实验结果聚焦肝脏驻留细胞的新论文；每次调用只问一个受限的肝细胞问题，同时保留配方、载荷、剂量、途径、模型、检测和比较证据。

Actual result

实际结果

The LLM returned multiple correctly linked experiments instead of one global record: six hepatocyte, three Kupffer-cell and four endothelial-cell arms—13 represented arms in total.

LLM 不再只返回一条全局记录，而是返回多条正确关联的实验：6 个肝细胞组、3 个 Kupffer 细胞组和 4 个内皮细胞组，共表示 13 个实验组。

What this application is now

这个应用现在是什么

A useful liver-LNP evidence builder that still requires arm-level completeness enforcement

一个有用的肝脏 LNP 证据构建器，但仍需实验组级完整性约束

The combined NP-002 output is useful for a foundational formulation database: it captures compositions, payloads, liver-cell recipients, administration, dose and major delivery outcomes. It is not yet reliable enough to claim complete dose-response or cell-targeting coverage without comparing the returned records against a deterministic inventory of expected experimental arms.

NP-002 的合并输出已适合构建基础配方数据库：它捕捉了组成、载荷、肝细胞受体、给药方式、剂量和主要递送结果。但在将返回记录与确定性的预期实验组清单比较之前，它还不足以宣称完整的剂量反应或细胞靶向覆盖。

What now works现在有效的部分Context-isolated calls produce multiple scientifically linked formulation–experiment–outcome records.情境隔离调用能够生成多条科学关联的配方—实验—结果记录。
What must come next下一步必须做什么Build the expected arm checklist locally, require a disposition for every arm, and reject “complete” status when any arm or required secondary field is absent.在本地建立预期实验组清单，要求每组都有处置；任何实验组或必需次级字段缺失时，都不得判定为“完整”。
